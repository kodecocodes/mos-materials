# macOS by Tutorials: Materials

This repo contains the downloadable materials and projects associated with the **[macOS by Tutorials, 1st Edition](https://www.kodeco.com/books/macos-by-tutorials)** from [Kodeco](https://www.kodeco.com).
Any subsequent updates can be found on [TrozWare](https://troz.net/books/macos_tutorials/), and the updated materials can be found [here](https://github.com/trozware/mos_book_code).

Each edition has its own branch, named `editions/[EDITION]`. The default branch for this repo is for the most recent edition.
